# Selections

Hand-picked image lists (one path per line, relative to the dataset folder, e.g. `cars_train/00001.jpg`; `#` comments allowed). These are small and tracked in git.

- `car_fronts.txt`: Stanford Cars images that show a clear, roughly frontal view (~60: 40 for the study + spares).
- `car_rears.txt`: a few rear views used as controls.
